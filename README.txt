NOTEBOOK 1.1.0 - setup (all files are flat, no folders)

1. Upload to the ROOT of your GitHub repo: index.html, style.css, app.js,
   MainActivity.java, icon.png, make_icons.py, package.json, capacitor.config.json
   (replace the old ones).
2. Workflow: in the repo choose Add file > Create new file, name it
   .github/workflows/build.yml and paste the contents of build.yml.
3. Open the Actions tab, run "Build Notebook APK", then download the
   Notebook-APK artifact (Notebook.apk) and install it.

What is new: pin notes (replaces Favorites), tags only (folders became tags),
Locked is a filter, 3-item nav, share text into Notebook, reminders,
biometric unlock, checklist progress, undo after delete, word count,
note colours, Trash auto-empties after 30 days, weekly backup reminder,
optional "open a new note on launch".
